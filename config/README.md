# Configuração

O arquivo `requirements-reproducao.txt` registra as principais versões usadas na execução documentada da Parte 2. A instalação normal do projeto utiliza o `requirements.txt` localizado na raiz.

Parâmetros e hashes específicos da avaliação permanecem em `src/parte2/protocolo_avaliacao.json`, junto dos dados aos quais se referem.
