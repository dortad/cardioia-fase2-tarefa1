# Parte 2 - Classificador básico de texto

## Objetivo

Treinar um classificador de risco clínico com base em frases curtas, usando TF-IDF e Logistic Regression.

## Arquivos

- `frases_risco.csv` — base simulada com frases e rótulos
- `classificador_risco.py` — treino e avaliação do modelo

## Execução

```bash
python fase2/parte2/classificador_risco.py
```

## Observação

A base foi criada de forma sintetizada para demonstrar a lógica da triagem clínica e deve ser expandida com mais dados em uma entrega final.
