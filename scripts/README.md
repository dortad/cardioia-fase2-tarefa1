# Scripts auxiliares

- `validar_entrega.py`: confere os arquivos obrigatórios, a execução salva do notebook e os links locais da documentação. É executado pela integração contínua e também pode ser usado localmente com `python scripts/validar_entrega.py`.

O executor reprodutível do notebook permanece em `src/parte2/executar_notebook.py`, junto do código e dos arquivos que utiliza.
